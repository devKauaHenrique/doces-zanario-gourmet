# 🍰 Zanário Gourmet - Site Oficial

Site institucional e catálogo digital desenvolvido para a confeitaria **Zanário Gourmet**, com foco na apresentação de produtos de forma elegante, responsiva e otimizada.

🔗 Acesse o projeto:  
https://zanario-gourmet.vercel.app/

---

## 📌 Sobre o projeto

Este projeto foi desenvolvido com o objetivo de:

- Apresentar os produtos da confeitaria de forma visual e atrativa  
- Facilitar o contato e conversão de clientes  
- Destacar campanhas sazonais (ex: Dia das Mães)  
- Garantir uma boa experiência tanto no desktop quanto no mobile  

---

## 🚀 Tecnologias utilizadas

- HTML5  
- CSS3  
- JavaScript  
- Vercel (Deploy e Analytics)  
- Google Analytics (monitoramento de usuários)

---

## 🎯 Funcionalidades

- ✅ Landing page moderna e responsiva  
- ✅ Banner dinâmico (slider) para campanhas  
- ✅ Seção de produtos organizados  
- ✅ Destaque para produtos mais vendidos  
- ✅ Botões de ação (CTA) estratégicos  
- ✅ Informações de entrega, pagamento e personalização  
- ✅ Layout adaptado para mobile  

---

## 📱 Responsividade

O site foi desenvolvido com foco em **mobile-first**, garantindo:

- Boa visualização em celulares  
- Ajustes de layout e tipografia  
- Imagens otimizadas para diferentes telas  

---

## 📊 Monitoramento de dados

O projeto conta com:

- 📈 Vercel Analytics → métricas básicas de acesso  
- 📊 Google Analytics → comportamento do usuário  

Esses dados ajudam na tomada de decisão e melhoria contínua do site.

---

## 🔄 Versionamento

O projeto utiliza duas principais branches:

- `main` → produção (deploy automático na Vercel)  
- `dev` → desenvolvimento e testes
